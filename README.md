## Что это за транспорт

Одноместное кресло с рожками, маленькими крыльями и реактивным котлом под сиденьем.
Вместо топлива — условные баллы грехов пассажира. Чем выше уровень грехов,
тем быстрее полёт. Отпущение грехов мгновенно убирает прибавку к скорости,
а крылья позволяют спокойно продолжить путь.

Вся механика помещается в один основной класс: взлететь, пролететь участок,
приземлиться, добавить грехи и отпустить их.

## Правила небесной канцелярии

| Правило | Как работает |
|---|---|
| Уровень грехов | Целое число от 0 до 100 |
| Базовая скорость | 30 км/ч |
| Прибавка за один грех | 2 км/ч |
| Максимальная скорость | 230 км/ч |
| Отпущение грехов | Уровень и прибавка обнуляются сразу |
| Полёт после отпущения | Продолжается со скоростью 30 км/ч |
| На земле | Скорость равна нулю, движение запрещено |
| Пройденный путь | Суммируется между участками и рейсами |

В воздухе скорость рассчитывается по формуле:

```text
скорость = 30 + 2 × уровень грехов
время участка = расстояние / скорость
```

Например, при уровне 100 аппарат пролетает 23 км за 6 минут. После отпущения
грехов за те же 6 минут он преодолеет 3 км. Ранее пройденный путь сохраняется,
а грехи во время движения не расходуются.

> «Ускорение от грехов» здесь означает прибавку к скорости.
> Физический разгон, высоту и аэродинамику моделировать не требуется.

## Задание разработчику

Репозиторий содержит спецификацию и тесты для самостоятельной реализации.

1. Изучите [SPEC.md](SPEC.md): свойства, сигнатуры методов, формулы и исключения.
2. Сверьтесь с [TEST_CASES.md](TEST_CASES.md): каждому кейсу соответствует тестовая функция.
3. Реализуйте модуль `chertolet` с классом `Chertolet` и исключениями
   `ChertoletError`, `FlightStateError` по заданному контракту.
4. Запустите тесты и добейтесь прохождения всех проверок.

Особое внимание уделите границам диапазонов, отпущению грехов в воздухе
и сохранению состояния после ошибочных команд.

## Как запустить тесты

Понадобятся **Python 3.10+** и **pytest 8 или 9**.
Из корня проекта создайте и активируйте виртуальное окружение:

```bash
python3 -m venv .venv
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установите pytest и запустите проверки:

```bash
python -m pip install "pytest>=8,<10"
python -m pytest -q test/
```

До выполнения реализации импорт модуля `chertolet` завершится ошибкой —
это ожидаемый исходный этап задания. После реализации тесты проверят
публичный интерфейс, расчёты, обработку ошибок и полные маршруты.
